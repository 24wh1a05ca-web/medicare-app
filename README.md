# 🏥 MediCare – Hospital Appointment App

MediCare is a Flutter-based hospital appointment application designed to provide users with a simple and convenient interface for managing hospital appointment-related activities.

## ✨ About the Project

MediCare aims to make the hospital appointment experience easier through a clean, user-friendly mobile application interface.

## 🚀 Features

- User-friendly application interface
- Hospital appointment-focused workflow
- Responsive Flutter UI
- Local preference storage using SharedPreferences
- Android emulator support

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| Flutter | Mobile application development |
| Dart | Programming language |
| SharedPreferences | Local data storage |
| Android Studio | Emulator and Android development |
| Git & GitHub | Version control and project hosting |

## ⚙️ Installation and Setup

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone https://github.com/24wh1a05ca-web/medicare-app.git
```

**2. Navigate to the project directory**

```bash
cd medicare-app
```

**3. Install dependencies**

```bash
flutter pub get
```

**4. Run the application**

```bash
flutter run
```
